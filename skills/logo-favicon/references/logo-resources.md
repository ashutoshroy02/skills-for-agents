## Python Libraries

| Library | Install | Purpose |
|---------|---------|---------|
| svgwrite | `pip install svgwrite` | Create SVG drawings |
| CairoSVG | `pip install cairosvg` | SVG → PNG/PDF conversion |
| Pillow | `pip install Pillow` | Image processing, resize, ICO |
| svgpathtools | `pip install svgpathtools` | SVG path manipulation |
| lxml | `pip install lxml` | SVG/XML parsing |
| potrace | `pip install potrace` | Bitmap → vector tracing |
| fonttools | `pip install fonttools` | Font manipulation |

## CLI Tools

| Tool | Install | Purpose |
|------|---------|---------|
| SVGO | `npm i -g svgo` | SVG optimization/compression |
| vtracer | `cargo install vtracer` | Bitmap → SVG (better than potrace) |
| potrace | `apt install potrace` | Bitmap → vector |
| Inkscape | `apt install inkscape` | Full SVG editor, CLI export |
| ImageMagick | `apt install imagemagick` | Image conversion, resize |
| sharp | `npm i sharp` | Node.js image processing |
| opentype.js | `npm i opentype.js` | Font → SVG path conversion |

## Quick Decision Matrix

| Need | Best Free Option |
|------|-----------------|
| Favicon from text | favicon.io |

| Logo from text | Logomaker.lol |
| Logo from AI | Bing Image Creator (free) |
| SVG from AI | OmniSVG.net or Recraft |
| Monogram | Logogram.io |
| Icon search | SVG Repo or Flaticon |
| Full brand kit | LogoLoom MCP |
| SVG optimization | SVGO CLI |
| Bitmap → SVG | vtracer (CLI) |
