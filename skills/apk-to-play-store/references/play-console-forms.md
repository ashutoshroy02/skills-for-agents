## SDK → Data safety map (AdMob + RevenueCat game)

| Data type | Collected | Shared | Required? | Purposes | Comes from |
|-----------|-----------|--------|-----------|----------|------------|
| Location → Approximate location | Yes | Yes | Required | Advertising or marketing; Analytics; Fraud prevention, security and compliance | AdMob |
| App activity → App interactions | Yes | Yes | Required | Advertising or marketing; Analytics | AdMob |
| App info and performance → Diagnostics | Yes | Yes | Required | Analytics; Fraud prevention, security and compliance | AdMob |
| Device or other IDs | Yes | Yes | Required | Advertising or marketing; Analytics; Fraud prevention, security and compliance | AdMob |
| Financial info → Purchase history | Yes | No | Optional (buyers only) | App functionality | RevenueCat (service provider) |

Game progress saved only on the phone is not "collected". Ephemeral processing: No.

Top questions: collects or shares data → Yes; encrypted in transit → Yes; deletion request → Yes only if real (in-app "Reset progress and delete my data" plus a support email).

Entering it: tick one checkbox, screenshot, then the next (dialogs shift the layout); save each page. A reload once wiped the whole draft.
