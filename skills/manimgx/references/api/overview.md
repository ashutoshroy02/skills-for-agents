# Reference

A video is a **scene**. It shows **mobjects** in its frame: shapes, text, formulas, graphs and surfaces. **Animations** change them over time, and **updaters** keep a rule at every frame. The **camera** decides what the frame shows, flat or in 3D. **Sound** and a **voice** play along. **Rendering** makes the video.

This reference tells each part in that order, with all that it can do: [Learn](<https://manimgx.academa.ai/user-guide/the-basics/index.md>) teaches the same story, one idea at a time.
